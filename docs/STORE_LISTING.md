# Chrome Web Store listing — DevLens

Copy these values into the [Developer Dashboard](https://chrome.google.com/webstore/devconsole).

## Store listing tab

**Name:** DevLens

**Summary** (max 132 characters):

> Privacy-first developer toolbox: decode JWTs, inspect and convert JSON, diff, generate API code. 100% local.

**Category:** Developer Tools

**Language:** English

**Description:**

```
DevLens is a fast, private toolbox for developers who work with APIs. Everything runs locally in your browser — no account, no server, no tracking, and it works offline.

JWT
• Decode header and payload with expiry / not-before status in your local timezone
• Verify HS/RS/PS/ES signatures locally (paste a secret or a public key)
• JWKS support: paste a whole key set, the right key is chosen by kid
• Security review: alg "none", jku/x5u/jwk, missing exp, long-lived tokens …
• Create HMAC-signed test tokens

JSON
• Format, minify, browse as a tree, search, JSONPath queries, one-click repair of broken JSON
• Convert to TypeScript, Zod, C# records, Python (Pydantic), Java records, Go structs, YAML, CSV and XML — and XML back to JSON
• Structural JSON diff with identity matching for arrays, ignore rules, side-by-side view, Markdown/JSON reports

HTTP
• Build requests (raw, form, multipart, GraphQL) and generate cURL, C# HttpClient, JavaScript fetch and Python requests
• C# models: typed request/response records, a client class and a usage example
• Import from cURL, raw HTTP or an OpenAPI document
• Optional saved requests (off by default; secrets are stripped)

DevTools panel
• A "DevLens" tab in Chrome DevTools: inspect API calls, decode Bearer tokens, copy any request as cURL / C# / fetch / Python (optional secret masking), and generate typed models + a C# client from the real response
• Journey view per request: final status with diagnosis, timing waterfall, redirect chain, CORS preflight, connection details and CDN/proxy hints inferred from response headers

Tools
• Base64, URL encode/decode, query-string parser/builder, Unix timestamps, UUID inspector, UUID v4/v7 / ULID / random string generators, SHA/HMAC hashes, webhook signature verifier (GitHub, Stripe, Slack, Shopify), regex tester, HTTP status code reference

Extras
• Right-click selected text → "Inspect with DevLens" opens the right tool automatically
• Light and dark themes, keyboard shortcut (Ctrl+Shift+L), Ctrl/Cmd+Enter to run

PRIVACY
DevLens never sends your tokens, JSON, headers or bodies anywhere. Its content security policy blocks all network access. Tool inputs are never stored. Only your theme and a few UI preferences are saved.

Made by Mohsen Bahrzadeh.
```

## Privacy tab

**Single purpose:**

> DevLens helps developers inspect, debug and transform API-related data (JWTs, JSON, HTTP requests and encoded
> strings) locally in the browser.

**Permission justifications:**

- `storage` — Saves the theme, last selected tab and default output language, the optional (opt-in) saved
  requests, and briefly passes text selected through the context menu to the side panel via in-memory session storage.
- `contextMenus` — Adds the "Inspect with DevLens" right-click item for selected text.
- `sidePanel` — Shows DevLens in Chrome's side panel, docked next to the page, instead of a popup that closes when you click away.
- Host permissions — none requested. No remote code is used.

**Remote code:** No, I am not using remote code.

**Data usage disclosures:** DevLens does not collect or transmit any user data. Leave all data-type boxes
unchecked and tick the three certifications:

- I do not sell or transfer user data to third parties, outside of the approved use cases.
- I do not use or transfer user data for purposes that are unrelated to my item's single purpose.
- I do not use or transfer user data to determine creditworthiness or for lending purposes.

**Privacy policy URL:** publish `PRIVACY.md` at a public URL and paste it here, for example
`https://github.com/<you>/devlens/blob/main/PRIVACY.md` or a GitHub Pages page.
